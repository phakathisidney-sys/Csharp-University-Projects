# C# First-Year University Coursework & Practical Assessments

## Overview
This repository contains C# programming projects, class practicals, and practical test solutions completed during my first-year Information Systems module at university. 

The focus of this module was building fundamental programming concepts, algorithm development, and object-oriented programming (OOP) using C# and the .NET framework.

## Core Concepts Covered
Fundamentals: Variables, data types, operators, and control structures (if/else, switch, loops).

Functions: Methods, parameter passing, return values, and scope.

Data Structures: One-dimensional and multi-dimensional arrays, lists, and string manipulation.

Object-Oriented Programming: Basic class structures, properties, constructors, and encapsulation.

Problem Solving: Translating problem statements into algorithmic solutions under timed test conditions.
